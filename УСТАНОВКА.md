# Установка NotchShelf

Панель, которая живёт в вырезе MacBook: скриншоты, буфер обмена, загрузки,
планы, калькулятор, конвертер, переводчик, музыка, погода и состояние
компьютера. Наводишь на чёлку — панель выезжает, наводишь ещё раз — уезжает.
Пока она закрыта, на экране нет ничего.

Нужен MacBook с вырезом и macOS 14 или новее. Без выреза приложение тоже
работает — панель выезжает полоской по центру верхнего края.

## Способ первый: одна команда

Открой Терминал (Cmd + пробел, набери «Терминал»), вставь строку и нажми Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/karazhaniman72-eng/notchshelf/main/scripts/install.sh | bash
```

Приложение скачается, встанет в «Программы» и сразу запустится. Больше ничего
делать не надо.

## Способ второй: руками

1. Скачай `NotchShelf-0.1.zip` со страницы
   [Releases](https://github.com/karazhaniman72-eng/notchshelf/releases).
2. Распакуй и перетащи `NotchShelf.app` в «Программы».
3. Открой Терминал и выполни одну строку — она снимает с приложения метку
   «скачано из интернета»:

   ```bash
   xattr -dr com.apple.quarantine /Applications/NotchShelf.app
   ```

4. Запусти приложение.

Без третьего шага macOS откажется его открывать: приложение не подписано
сертификатом Apple, а он стоит 99 долларов в год. Проверить, что внутри, можно
по исходникам — они целиком лежат в этом же репозитории.

## Что дальше

- **Значка в Dock нет** и окна тоже нет. Всё управление — иконка в строке меню
  справа: там же и «Выйти».
- **Разрешения приложение спрашивает по одному** и только когда открываешь
  соответствующую вкладку. Календарь — для вкладки «Планы», управление Spotify —
  для «Музыки», запись экрана — только когда нажмёшь «Запись». При запуске не
  спрашивается ничего.
- **Скриншоты появляются на полке сами.** Если полка пустая, macOS у тебя
  сохраняет скриншоты в буфер обмена, а не файлом — проверь Shift-Cmd-5 →
  «Сохранить в» → «Рабочий стол» или отдельную папку.
- **Ollama** нужна только для двух вещей: задачи словами в калькуляторе и
  перевод без интернета. Не установлена — эти две вкладки работают без слов,
  остальное вообще не замечает.

## Удалить

Перетащи `NotchShelf.app` из «Программ» в корзину. Настройки лежат в
`~/Library/Preferences/local.iman.notchshelf.plist`, журнал — в
`~/Library/Logs/NotchShelf.log`.
